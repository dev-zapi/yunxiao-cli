# YunXiao MR 创建技能

## 功能

帮助开发者快速创建云效 MR（合并请求），支持：

- 自动从分支名推断工作项 ID
- 自动查询并关联工作项
- 固定标题格式：`<工作项ID>：<MR标题>`
- **使用 pr-documentation 技能生成专业的 MR 描述**
- 智能询问缺失信息
- 简洁输出 MR 编号和链接

## 使用方法

技能已配置为自动触发，当用户说以下内容时：

- "创建 MR"
- "创建合并请求"
- "发起合并"
- "把某分支合并到某分支"
- "使用本分支创建 MR"

## 示例

### 基本用法

```
用户: 创建 MR

技能:
1. 查询当前分支 (git branch --show-current)
2. 推断工作项编号 (从分支名，如 feat/PROJ-9999 → PROJ-9999)
3. 查询项目获取 space-id
4. 查询工作项获取 workitem-id
5. 查询 git log 和 diff 获取变更信息
6. **调用 pr-documentation 技能生成 MR 描述**
7. 组合标题：PROJ-9999：示例详情页面重构
8. 创建 MR

输出:
✅ MR 创建成功

MR 编号: 292
MR 链接: https://codeup.aliyun.com/xxx/change/292
关联工作项: PROJ-9999 (000000000000000000000001)
```

### 指定分支

```
用户: 创建 MR，从 feat/login 合并到 main

技能:
1. 使用指定的源和目标分支
2. 推断工作项编号
3. 查询工作项详情
4. 生成描述
5. 组合标题：<工作项ID>：<从commit提取的标题>
6. 创建 MR

输出:
✅ MR 创建成功
MR 编号: 293
MR 链接: https://...
关联工作项: PROJ-xxxx (yyy)
```

### 提供概述

```
用户: 创建 MR，这是一个新的支付模块，支持微信支付

技能:
1. 查询当前分支和 commit 信息
2. 结合用户描述 + 自动提取的技术细节
3. 推断工作项编号
4. 组合标题：<工作项ID>：新的支付模块，支持微信支付
5. 创建 MR

输出:
✅ MR 创建成功
MR 编号: 294
MR 链接: https://...
关联工作项: PROJ-xxxx (yyy)
```

## 标题格式说明

**固定格式**：`<工作项ID>：<MR标题>`

**示例**：
- `PROJ-9999：示例详情页面重构`
- `wi-123：添加用户认证功能`

工作项ID和标题之间使用中文冒号分隔。

## 技能依赖

- **yunxiao-cli**: 云效命令行工具（查询仓库、分支、工作项、创建 MR）
- **pr-documentation**: PR 文档生成技能（生成专业的 MR 描述）

## 工作流程

1. 收集必要信息（分支、工作项、仓库）
2. 查询 git 变更（log、diff、stat）
3. **调用 pr-documentation 技能生成描述**
4. 组合标题（工作项ID + 简要描述）
5. 创建 MR 并关联工作项
6. 输出结果
